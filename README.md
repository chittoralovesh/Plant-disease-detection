## 🌟 What is this?

> **Plant Disease Detection** is a deep-learning powered tool that diagnoses sick plants from a single photo of a leaf. 🍂  
> Upload a leaf, get an answer in **under a second**, plus suggested remedies.

## ⚙️ Quick Start (60 seconds ⏱️)

<details open>
<summary><b>🧰 Prerequisites</b></summary>

- Python **3.9+**
- `pip` & `venv` (or `conda`)
- A leaf 🍃 (real or digital)

</details>

### 🪄 Step 1 — Clone it
```bash
git clone https://github.com/chittoralovesh/Plant-disease-detection.git
cd Plant-disease-detection
```

### 🌱 Step 2 — Spin up a virtual env
```bash
# macOS / Linux
python -m venv venv && source venv/bin/activate

# Windows
python -m venv venv && venv\Scripts\activate
```

### 📦 Step 3 — Install dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 🚀 Step 4 — Launch the app
```bash
cd app
streamlit run main.py
```

> 🎉 Open **http://localhost:8501** and start diagnosing!

## 🧠 The Brain Behind It

<div align="center">

| 🔧 Component | 📋 Details |
|:--|:--|
| **Architecture** | Convolutional Neural Network (CNN) |
| **Input Shape** | 224 × 224 × 3 RGB |
| **Layers** | Conv2D → BatchNorm → MaxPool → Dropout → Dense |
| **Optimizer** | Adam (lr = 1e-3) |
| **Loss** | Categorical Cross-Entropy |
| **Framework** | TensorFlow / Keras |

Trained on the legendary **[PlantVillage Dataset](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)** — over **54,000 expert-labeled images** across **38 disease classes** spanning **14 crop species**.
